# 신더의 기억지도

신더와 함께 부산의 역사와 오늘의 관광 명소를 탐험하는 로컬 웹페이지입니다.

**웹사이트 바로가기: [신더의 기억지도](https://lostnumbers-lab.github.io/cinder-memory-map/)**

위 주소는 실제 메인 화면이며, `github.com/LostNumbers-lab/cinder-memory-map`은 소스 코드를 관리하는 저장소입니다. GitHub Pages는 `main` 브랜치 루트의 `index.html`을 메인 페이지로 배포합니다.

## 실행

저장소를 다운로드하거나 클론한 뒤 `index.html`을 브라우저에서 여세요. 설치, 빌드, 서버 실행 및 로그인은 필요하지 않습니다. 이미지와 글꼴도 저장소에 포함되어 있습니다.

## 주요 기능

- **기억 속 부산**: 40계단, 보수동 책방골목, 영도다리의 이야기
- **오늘의 부산**: 영화의전당·BIFF, BIFF광장, 광안리·광안대교, 해운대, 감천문화마을
- 장소별 소개, 대표 이야기, 여행 포인트와 공식 자료 링크
- 읽은 이야기 저장 및 나의 기록 확인 (`localStorage`)
- 화면 크기에 맞춘 반응형 레이아웃과 배경음 켜기/끄기
- 장소별 이야기와 연결된 신더 일러스트 8종, 지도·앨범을 든 안내 캐릭터 2종

## 파일 구성

| 파일 | 용도 |

## 신더 이미지

첨부된 캐릭터 원본과 전후측면 참고 이미지를 바탕으로 제작했습니다. 캐릭터의 불꽃 머리, 호박색 눈, 망토와 그릇 모양 몸체를 유지하면서 장면에 맞게 포즈를 달리했습니다.

- 40계단: 작은 등불을 들고 계단 오르기
- 보수동: 헌책과 책갈피 읽기
- 영도다리: 편지를 소중하게 품기
- 영화의전당: 영화 슬레이트를 들고 안내하기
- BIFF광장: 핸드프린팅 살펴보기
- 광안리: 카메라로 야경 담기
- 해운대: 조개껍데기로 바다 소리 듣기
- 감천문화마을: 스케치북에 마을의 색 담기
- 오늘의 부산·여행 코스·이용 방법: 여행 지도를 든 안내 포즈
- 기억 속 부산·나의 기록: 기억 앨범을 든 포즈

이미지는 `assets/cinder/`에 포함되어 있으며, 생성 프롬프트는 같은 폴더의 `generation-prompts.json`에 기록했습니다. 건축물과 배경은 이야기를 위한 창작 재구성입니다.

## 콘텐츠와 출처

지도 배경은 공식 관광 사진 등을 참고해 생성한 창작 일러스트로, 실제 지리·거리·시대별 지도 또는 실시간 풍경이 아닙니다. 신더의 대사와 편지는 창작이며, 공식 자료를 참고한 소개 및 역사 해설과 구분해 제공합니다. 공식 자료 링크는 장소별 소개창에 있습니다.

온글잎 베리려원 글꼴의 출처와 저작권 안내는 `assets/fonts/FONT-LICENSE.txt`를 확인하세요. 포함된 이미지와 글꼴의 권리는 각 권리자에게 있습니다.

메인 체험은 오프라인에서 사용할 수 있습니다. Google Analytics 태그는 인터넷에 연결된 경우 외부 Google 스크립트를 불러옵니다. 지도와 공식 자료 링크는 선택할 때 외부 사이트로 연결되므로 인터넷이 필요합니다. 로컬 파일의 기록 저장 여부는 브라우저 설정에 따라 달라질 수 있습니다.
